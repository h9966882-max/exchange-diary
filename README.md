# Exchange Diary

A deliberately slow, private exchange diary for Hiroisa × Atsushi.

## Vol.001
- 7 pages
- Hiroisa writes odd pages; Atsushi writes even pages
- Write → hand over → wait → receive → read
- Delivered pages are locked
- Closed volumes return to the bookshelf

## Privacy
This public repository contains application code only. Diary text and photos live privately in Supabase. The diary UI requires authentication and server-side owner allowlisting.
